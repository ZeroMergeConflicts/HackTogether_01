TRY LIVE INTERACTION:
COST-CONTROLLED INGESTION

SHA-256 Incremental Hashing

Files are hashed locally before any AI call. Unchanged files are skipped instantly, protecting your Gemini API free-tier quota.

SHA256(file) == db.hash → SKIP
INTENT ROUTER

Smart Conditional Retrieval

Casual greetings, math calculations, and time queries are handled instantly without touching SQLite or wasting LLM tokens.

STRUCTURED EXTRACTION

Strict JSON Schema Output

Extracts normalized entities, people, events, dates, deadlines, actions, and ₹/$ amounts directly into relational SQLite tables.

SECURITY BOUNDARY

Prompt-Injection Defense

Document contents are strictly sandboxed as untrusted data, preventing malicious instructions inside PDFs or notes from hijacking prompts.

SYSTEM PIPELINE

From raw filesystem to grounded intelligence.

01

FolderScanner & SHA-256

Discovers `.pdf`, `.png`, `.jpg`, `.txt`, `.md`, `.csv`, and `.json` files and computes cryptographic hashes to detect modifications.

backend/ingestion/scanner.py
02

AIAnalyzer & AIClient

Sends new or modified files to Gemini 2.5 Flash with strict JSON schema enforcement to extract events, deadlines, actions, and amounts.

backend/ai/analyzer.py
03

SQLite Relational Graph

Persists files, structured contexts, entities, and cross-document relationships (`same_topic`, confidence scores, shared entities).

backend/database/database.py
04

Intent & Query Synthesis

Classifies user intent, scores relevant records, deduplicates facts, and returns natural-language answers with separated source citations.

backend/services/query_service.py
